chromeブラウザのインストール
1. https://www.google.com/intl/ja/chrome/　から「chromeをダウンロード」をクリックします。


配布用サイネージアプリのインストール
1. Cドライブ直下等にsignageフォルダを作成します。
2. USB等に準備した配布用signage-app.zipを解凍し、中にある5つのファイルをsignageフォルダにコピーします。
3. chromeブラウザで管理画面URLにログインし、このPCに表示させる物件のコマンドをコピーします。
4. signage-big.bat及びsignage-small.batの中身を先ほどのコマンドにペーストし保存します。bigのみ--kioskを付けます。
5. 2つのバッチファイルをダブルクリックしてどちらも動作することを確認。
6. 起動されたアプリはESCキーかctrl+Qで終了できます。


Windows 11 スタートアップへの登録

PCの電源が入った際に、バッチファイルを自動実行させます。
1. キーボードの `Windowsキー + R` を同時に押して「ファイル名を指定して実行」を開きます。
2. 入力欄に `shell:startup` と入力して「OK」を押します。
3. `signage-big.bat` のショートカットを作成し、このスタートアップフォルダの中に配置します。


chromeリモートデスクトップの設定

ホスト側（このPC）の設定手順
1. Chromeを開き、Chrome リモート デスクトップ アクセス設定ページ（remotedesktop.google.com/access）にアクセス。
2. 「リモート アクセスの設定」にあるダウンロードボタン（青い矢印アイコン）をクリックします。
3. Chrome ウェブストアが開くので、「Chromeに追加」をクリックして拡張機能を追加します。
4. インストーラーがダウンロードされるので実行し、画面の指示に従ってインストールを進めます。
5. パソコンの名前を入力し、接続時に使用する6桁以上のPIN（暗証番号）を設定して「起動」をクリックします。
6. ステータスが「オンライン」になれば準備は完了です。

クライアント側（操作するパソコン・スマホ）からの接続方法
1. 操作する端末でも同じChromeを開き、同じGoogleアカウントでログインします。
2. Chrome リモート デスクトップのページを開きます。
3. 登録したパソコンの一覧から、接続したいパソコン名をクリックします。
4. 事前に設定したPINコードを入力して接続します。

Windows のサービス設定を確認する
Chrome リモート デスクトップの常駐サービスが「自動起動」になっているか確認します。
1. キーボードの Windowsキー + R を同時に押し、services.msc と入力してEnterを押します。
2. サービスの一覧から 「Chrome Remote Desktop Service」 を探してダブルクリックします。
3. スタートアップの種類 が 「自動」 になっているか確認します。もし「手動」や「無効」になっていたら「自動」に変更します。
4. サービスの状態が「停止」になっている場合は、「開始」ボタンをクリックします。
5. 「OK」をクリックして画面を閉じます。


パソコンのスリープ・休止状態を解除する
パソコンが「スリープ状態」や「休止状態」に入ってしまうと、外部からの接続を受け付けなくなりオフラインになります。
1. Windowsの「設定」（Windowsキー + I）を開き、「システム」 ＞ 「電源とバッテリー」（または「電源とスリープ」）に進みます。
2. 画面がオフになる時間ではなく、「スリープ」の項目を「なし」（または「適用しない」）に設定します。


Windows Updateを手動に切り替える（WIndows11Proのみ）

バックグラウンドで勝手にダウンロードやインストールが実行されなくなります。回収後に「設定」画面から手動で「更新プログラムのチェック」を押せば、通常通りアップデートが可能です。
1. キーボードの Win + R キーを押し、gpedit.msc と入力してEnterを押します。
2. 左のツリーから以下を順に展開します：
コンピューターの構成 ＞ 管理用テンプレート ＞ Windows コンポーネント ＞ Windows Update ＞ エンド ユーザー エクスペリエンスの管理
3. 右側のリストから 「自動更新を構成する」 をダブルクリックします。
4. ウィンドウ左上のステータスを 「有効」 に変更します。
5. 左下のオプションにある「自動更新の構成」のドロップダウンから 「2 - ダウンロードおよび自動インストールを通知」 を選択し、[OK] をクリックします。
