ステップ2：EC2へのアクセスとserver.pyのデプロイ
SSH で Ubuntu へ接続し、必要な環境をセットアップします。以下のコマンドを順に実行：

コマンドプロンプトを「管理者として実行」し、次を実行してください。

takeown /f signage-key.pem

icacls signage-key.pem /reset
icacls signage-key.pem /inheritance:r
icacls signage-key.pem /remove:g "NT AUTHORITY\Authenticated Users"
icacls signage-key.pem /remove:g "BUILTIN\Users"
icacls signage-key.pem /remove:g "Everyone"
icacls signage-key.pem /grant:r "%USERNAME%:R"

icacls signage-key.pem
表示結果に、自分のユーザー名だけが読み取り権限として残っていれば問題ありません。

ssh -i /path/to/your-key.pem ubuntu@<EC2のパブリックIP>

# システム更新
sudo apt update && sudo apt upgrade -y

# Pythonと必須ツールをインストール
sudo apt install -y python3 python3-pip python3-venv git

# Gitリポジトリをクローン
git clone https://github.com/SCSKQ-Okabe/signage.git

# Python仮想環境の作成
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install fastapi uvicorn python-multipart
pip install passlib
pip install bcrypt==4.3.0

python3 server.py

このままだと起動ログがターミナルに流れ続けます。
別タブで確認する場合は、もう一度 EC2 にSSH接続して以下を実行してください。

curl -I http://localhost:8000/admin
もし 200 などが返れば、アプリは起動しています。

パブリックIP経由でアクセス確認
ブラウザで以下にアクセスします。

http://<EC2のパブリックIP>:8000/admin
例:
http://13.230.123.45:8000/admin
ここで画面が見えれば、Step 2 は完了です。

ステップ3：AWSセキュリティグループで8000番ポートを許可
AWSコンソールで以下を開きます。

EC2
インスタンス
対象インスタンスを選択
「セキュリティ」タブ

関連付けられたセキュリティグループをクリック
「インバウンドルール」→「インバウンドルールを編集」
ルールを追加

タイプ: カスタムTCP
ポート範囲: 8000
ソース: 自分のIP

どこからでもアクセス可能にする場合
セキュリティグループのインバウンドルールを変更してください。

タイプ: カスタムTCP
ポート範囲: 8000
ソース: 0.0.0.0/0
これなら、世界中どこからでもポート8000にアクセス可能になります。
ただし、本番環境では非常に危険です。
理由：
認証なし → 誰でも管理画面に入れる
SQLite データベースが直接露出
PDF ファイルが無保護

ステップ4：Systemdサービス登録（常時起動）
server.py を 24/7 稼働させるため、Linuxのサービスとして登録します。

bash
# サービスファイルを作成
sudo nano /etc/systemd/system/signage-server.service
以下を貼り付け：

INI
[Unit]
Description=Signage Server
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/signage-app
ExecStart=/home/ubuntu/signage-app/venv/bin/python3 server.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
保存後、サービスを有効化：

bash
sudo systemctl daemon-reload
sudo systemctl enable signage-server
sudo systemctl start signage-server
sudo systemctl status signage-server  # 状態確認

ステップ7：ALB（Application Load Balancer）または Nginx の設定
Nginx をリバースプロキシとして設定（推奨：簡単）：

bash
sudo apt install -y nginx

# Nginx設定
sudo nano /etc/nginx/sites-available/default
以下を貼り付け：

Nginx
server {
    listen 80;
    server_name your-domain.com www.your-domain.com;
    
    # HTTPをHTTPSにリダイレクト
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com www.your-domain.com;
    
    # SSL証明書（ACMから取得）
    ssl_certificate /path/to/your-cert.crt;
    ssl_certificate_key /path/to/your-key.key;
    
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
Nginx起動：

bash
sudo systemctl restart nginx
sudo systemctl enable nginx
