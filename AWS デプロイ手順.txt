本番用に bind 先だけ一時的に修正
現状の server.py はローカル(127.0.0.1) に向いています。EC2 上で外部アクセスさせるため、起動時の IP を 0.0.0.0 に変更します。

bash
python3 - <<'PY'
from pathlib import Path
p = Path("server.py")
text = p.read_text()
old = 'uvicorn.run(app, host="127.0.0.1", port=8000)'
new = 'uvicorn.run(app, host="0.0.0.0", port=8000)'
if old in text:
    text = text.replace(old, new)
    p.write_text(text)
    print("updated host binding")
else:
    print("pattern not found")

現在、server.py は ローカルホスト（127.0.0.1） に設定されています。これを AWS本番URL に変更する必要があります。

修正対象行：

100行目：mobile_url = f"http://127.0.0.1:8000/mobile/{project_id}"
397行目：uvicorn.run(app, host="127.0.0.1", port=8000)
まず、Route 53でドメインを取得したら、以下を修正してください：

bash

Python
# 100行目付近
mobile_url = f"https://your-domain.com/mobile/{project_id}"  # 「your-domain.com」は取得したドメインに変更

# 397行目付近（本番では外部アクセス対応）

ステップ4：Systemdサービス登録（常時起動）
server.py を 24/7 稼働させるため、Linuxのサービスとして登録します。

bash
# サービスファイルを作成
sudo nano /etc/systemd/system/signage-server.service
以下を貼り付け：

INI
[Unit]
Description=Signage Server
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/signage-app
ExecStart=/home/ubuntu/signage-app/venv/bin/python3 server.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
保存後、サービスを有効化：

bash
sudo systemctl daemon-reload
sudo systemctl enable signage-server
sudo systemctl start signage-server
sudo systemctl status signage-server  # 状態確認

ステップ7：ALB（Application Load Balancer）または Nginx の設定
Nginx をリバースプロキシとして設定（推奨：簡単）：

bash
sudo apt install -y nginx

# Nginx設定
sudo nano /etc/nginx/sites-available/default
以下を貼り付け：

Nginx
server {
    listen 80;
    server_name your-domain.com www.your-domain.com;
    
    # HTTPをHTTPSにリダイレクト
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com www.your-domain.com;
    
    # SSL証明書（ACMから取得）
    ssl_certificate /path/to/your-cert.crt;
    ssl_certificate_key /path/to/your-key.key;
    
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
Nginx起動：

bash
sudo systemctl restart nginx
sudo systemctl enable nginx
